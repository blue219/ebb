# Ebb

Ebb helps a signed-in person define and execute a clear scope for liked videos on their Douyin account.

## Language

**Clear scope**:
The set or maximum number of account likes that one clear task is allowed to remove.
_Avoid_: Selection mode, delete mode

**All scope**:
A clear scope containing every like on the signed-in account when the task begins.
_Avoid_: Select all, visible likes

**Limited scope**:
A clear scope capped at a positive number of likes from the signed-in account.
_Avoid_: Partial all, batch selection

**Manual selection**:
A clear scope containing only the liked videos explicitly checked in the table.
_Avoid_: Custom amount, limited scope
